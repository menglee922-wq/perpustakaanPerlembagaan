# Perlembagaan Learning Library

Laman statik berbahasa Melayu untuk pembelajaran Perlembagaan Persekutuan. Buka `index.html` dalam pelayar moden.

## Halaman

- `index.html` - halaman utama dan carian
- `library.html` - 17 bahagian perpustakaan
- `article.html?id=perkara-12` - halaman topik individu
- `revision.html` - ulang kaji pantas
- `quiz.html` - kuiz tempatan
- `favourites.html` - topik yang disimpan
- `full-version.html` - pembaca dokumen sumber lengkap
- `about.html` - penerangan penggunaan

Kandungan pembelajaran disusun dalam `data/topics.js`, soalan dalam `data/quizzes.js`, dan fungsi halaman dipisahkan ke dalam fail JavaScript masing-masing.

Dokumen penuh yang disimpan secara setempat dalam `assets/`:

- *Perlembagaan Persekutuan, Cetakan Semula 2020* (sebagaimana pada 15 Oktober 2020)
- *Akta Pendidikan 1996 (Akta 550)*
- *Akta Bahasa Kebangsaan 1963*
- Salinan tambahan *Perlembagaan Persekutuan, Cetakan Semula 2020*

Huraian mudah adalah bahan pembelajaran dan bukan teks perundangan atau nasihat undang-undang.
